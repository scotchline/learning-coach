# Learning log

This file is yours. Keep it wherever you keep your notes. At the start of a session, paste it into the chat (or attach it) and write "quiz me from my log". At the end of a session, the coach gives you a new entry to add.

## Review queue

The questions you want to be asked again. Write them in your own words. Change the date each time you are quizzed: a later date if you got it right, one to two days if you did not.

## Writing profile

Only if the coach helps you with your writing. Paste this section before you write or ask for a fix, and the coach starts with what to watch for. It stays short: the coach gives it back updated, so you replace the old version.

**How I write:** who I usually write to, how formal I am, phrases to keep, things never to add.
